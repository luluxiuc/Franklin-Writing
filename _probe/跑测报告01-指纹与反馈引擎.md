# 跑测报告 01：v0.3 第 1 层指纹与第 11 节反馈引擎

**目的：** 用一篇真实文本端到端跑通 v0.3 的统计指纹与反馈判定，重点检验一个特定风险——
**系统会不会把用户训练成"像 AI 所描述的作者"，而不是"像作者本人"。**

**语料：** 汪曾祺《端午的鸭蛋》（[中国文艺网全文](https://www.cflac.org.cn/wywzt/2014/DuanWu/yuedu/201405/t20140529_257288.html)）。6 个作者行文段 + 1 段袁枚《随园食单》引文（引文段已排除出作者指纹）。1351 字（去标点）。
**说明：** 语料源文有一处截断（第 2 段末尾"但是《腌蛋》这一条我看后却"缺"很感兴趣"之类收尾），不影响本次结论。

**工具：** `_probe/analyze_fingerprint.py`、`_probe/engine_probe.py`、`_probe/verify_details.py`（纯本地计算，不调用任何模型）

---

## 一、实测指纹：我先说错了一件事

跑测之前，如果我凭印象写这位作者的风格，我会写"善用短句、节奏短促"。**实测数据不支持这个描述。**

| 指标 | 实测值 |
| --- | --- |
| 句子数 / 小句数 | 76 / 179 |
| **句长** | 均 17.8 字，中位 16.5，**标准差 10.0** |
| **小句长** | **均 7.5 字**，中位 7，标准差 3.8 |
| 句长分布 | 0-6字:8  7-10字:14  11-15字:13  16-20字:14  21-30字:18  31+字:9 |
| 逗号 / 句号（每百字） | 6.9 / 4.7（比值 1.48） |
| 最长连续短句串（≤8 字） | **2** |
| 直接命名情绪的词汇 | **2 次**（仅"高兴"，见第二节） |
| 显性连接词密度 | 0.74 / 百字 |
| 人称代词密度 | 2.07 / 百字，其中"我"占 60.7% |
| 具体名物 | 47 种，共出现 165 次（约每 8 字一个实物） |
| 问句 | 4 处，全部自问不答 |
| 不确定表达 | 不知 / 记不清 / 数不出 / 也许 / 不一定 / 大概 / 好像 / 说是，各 1 次 |

### 结论 1：这位作者不是"短句作者"，而是"小句作者"

句长均值 17.8 字、标准差 10.0、最长连续短句串只有 2——**从句子层面看，他的节奏一点都不短促，反而张弛很大**（最短 1 字，最长 43 字）。

真正的特征在下一级单位：**小句均长 7.5 字，标准差不小（3.8）**。179 个小句分布在 76 个句子里，平均每句 2.4 个小句。他真正在做的事是：

> **把长句子拆成 3～10 字的小句，用逗号快速连缀。**

第 1 段的小句长度序列（前 32 个）：

```
5, 9, 4, 9, 5, 6, 6, 13, 4, 7, 6, 7, 5, 3, 6, 5,
2, 9, 15, 15, 7, 4, 9, 7, 5, 14, 6, 4, 18, 9, 11, 4
```

这段序列本身就是节奏。而且其中出现过**连续 8 个 ≤6 字的小句**。这个结构在句子级指标上完全不可见。

**"短句"是一个任何模型都能随口给出的、指向错误的通用结论。** 如果系统把这个印象作为训练目标喂给用户，用户会去写一行一行的短句——那恰恰不是这位作者。这是代理漂移的第一个实证。

### 结论 2：情绪不是"不写"，是不"陈述"

全文直接情绪词只有 2 次，都是"高兴"：

- 「我对异乡人称道高邮鸭蛋，是**不大高兴**的」——否定式，且是态度判断
- 「什么时候孩子**一高兴**，就把络子里的鸭蛋掏出来，吃了」——作条件状语（一……就……）

两处都不是"陈述情绪"：没有一处是"他很高兴"这种以情绪为谓语的句子。**真正该判定的不是"有没有情绪词"，而是"情绪词有没有作为谓语出现在主句里"。**

### 结论 3：其余稳定特征

- **清单式谓词起句**：不用连接词，靠并置陈列。"系百索子。五色的丝线拧成小绳，系在手腕上。做香角子。……贴五毒。……贴符。……喝雄黄酒。"主语大量省略，每个动作独占一句或一小句。
- **具体名物承载情感**：47 种实物、165 次出现，全篇几乎不写抽象感受。"鸭蛋、络子、丝线、萤火虫、薄罗"这些物件自己完成了抒情。
- **雅俗落差**：雅词之后立刻自我拆台。"曾经沧海难为水"→"他乡咸鸭蛋，我实在瞧不上"；"所食鸭蛋多矣"→"还不就是个鸭蛋！"；"肃然起敬"→"哦！你们那里出咸鸭蛋！"
- **不确定性的权重**："记不清""数不出了""不一定真凑足十二样"——把"我记不清"写进正文本体，不修复成确定叙述。
- **口语收束**：以"吗／呢／罢了／极了"结束，语气是"说话"不是"作文"。

## 二、打靶结果：哨兵测试失败

设置三个测试文本，用同一套判定规则打分：

1. **用户临摹稿**——我刻意用"AI 泛化文风"写：平滑、连接词充足、句句完整、解释充分。
2. **哨兵文本**——**原文自己的句子**（第 1 段开场那句）。这是最"作者"的文本。**任何"偏离"都是假阳性。**
3. **按实测指纹构造的临摹稿**——我刻意照 7.5 字小句、清单式起句、口语收束来写。

### 缺陷一：系统把作者本人判为偏离作者

哨兵文本（原文原句）被检出 **2 条重要问题 + 2 条次要问题**：

```
【原文原句（哨兵）】
  [重要问题]
    - 节奏起伏：小句长标准差 2.4 vs 作者 3.8
    - 句法骨架：清单式起句 0/7 句（0%）vs 作者约 30~40%
  [次要问题]
    - 口语性：未出现「罢了／吗／呢／极了」一类口语收束
    - 疑而未答：未出现问句；原文 76 句中有 4 处自问
```

其中"清单式起句 0/7"**明显是假的**。逐项排查后确认是**计量单位错误**：

| 计量单位 | 谓词/属项起句比例（第 1 段） |
| --- | --- |
| 小句级 | 13/65 = 20% |
| 句级 | 8/26 = 31% |

哨兵文本由 8 个 ≤6 字小句构成，**正是该特征最密集的形态**，却因为按句子切分而全部漏检（首个小句是"五色的丝线拧成小绳"，不以谓词起句）。**指标在错误的层级上取样，就会把目标的典型形态判为偏离。**

### 缺陷二：三个指标的假阳性是结构性的，不是调参问题

| 指标 | 哨兵结果 | 真实原因 |
| --- | --- | --- |
| 节奏起伏（小句标准差） | 判为"过于均匀" | **标准差随样本量变化**。7 个小句算出的 2.4，与 179 个小句算出的 3.8 不可比。指标本身没有归一化，短段落必然被判为单调 |
| 句法骨架（清单式起句） | 判为 0% | 计量单位错误（见上） |
| 疑而未答（问句数 = 0） | 判为偏离 | **把"没有出现"当作缺陷**。原文 4 处问句分布在 76 句里，绝大多数段落本来就没有问句。这是纯噪声 |
| 口语性（语气词） | 判为偏离 | 同上，低频特征被当作必备特征 |

**四条里没有一条能靠调阈值修好**，因为它们不是阈值问题，而是"把全体统计分布里的稀有项当成逐段必备项"这一类建模错误。

### 缺陷三：最讽刺的一条——正确的临摹被判得比错误的更重

按实测指纹构造的临摹稿（小句均长 4.3 字，比作者的 7.5 字更接近"短促"）：

```
【临摹稿（按实测指纹构造）】
  指纹: 86字 11句 句长7.8±3.5 小句4.3±1.6 逗10.5 句12.8
  [核心问题]
    - 情绪表达：出现直接情绪词 [('高兴', 1)]
```

被判核心问题的那个"高兴"，来自我写的"孩子一高兴，掏出来，吃了"——**这正是原文原句**「什么时候孩子一高兴，就把络子里的鸭蛋掏出来，吃了」。同一作者、同一词语、同一用法、同一句法位置，被判为"直接命名情绪"的严重偏离。

而真正错误的用户稿（35.9 字长句、连接词密度是作者 3.2 倍）拿到的核心问题只有 1 条，两者**严重程度相当**。

### 汇总：错误方向是一致的

| 被系统惩罚的特征 | 在真实作者身上 |
| --- | --- |
| 平滑长句、显性连接词、"因为/所以/因此" | 作者极少用（0.74/百字） |
| 主语完整、句句交代清楚 | 作者大量省略主语 |
| 程度副词、解释性表述 | 作者只在极少数处直白感叹 |
| 抽象概括 | 作者落在具体实物上 |

也就是说，**这套判定实际在奖励"通顺、完整、有逻辑、有解释"的通用好文风，惩罚这位作者真正的特征。** 一个真实用户面对这些反馈会做的事很清楚：加连接词、把句子写完整、少堆实物、把情绪说出来——**他会越来越像一个"文从字顺的普通写作者"，而不是越来越像汪曾祺。**

这正是所说的"被带偏到 AI 评判解读作者的方向"。而且它不需要任何恶意：**只要指标对"通用规范"敏感、对"作者特征"不敏感，训练压力就自动指向通用规范。**

## 三、根因：三层结构与判定权限

这次失败不是建模质量不够，而是**权限分配错了**。

v0.3 §5 已经规定：第 1 层是"可靠计算、完全可复现"，第 2 层才是"LLM 判定 + 证据"。但**跑测中真正在做判定的，是第 1 层的数字**——"小句标准差 2.4 vs 3.8"直接变成了"重要问题"。第 1 层没有判定权，却在行使判定权。

正确的分工：

| 层 | 权限 |
| --- | --- |
| 第 1 层 统计指纹 | **只能描述，不能判定。** 输出"原文小句均长 7.5±3.8，本段 4.3±1.6"，不输出"节奏不像" |
| 第 2 层 LLM 判定 | 唯一有权说"像/不像"的层，且必须带原句证据与置信度 |
| 哨兵回归 | **每次改判定规则后必须重跑**：把原文句子喂进系统，必须零偏离。有偏离说明规则错了，不是作者错了 |

---

## 四、对 v0.3 的必要修订

跑测给出的结论直接落到文档修订上：

1. **作者模型增加第 4 层：与同类的差异。** 只有"这位作者与同时代同类作者不同"的部分才具有训练价值。"短句"不是差异，"小句均长 7.5 字 + 连续 8 个 ≤6 字小句"才是。
2. **区分四种特征类型，权限不同**：
   - 分布型（小句长度、标点密度）——只能整篇比，禁止逐段判缺；必须做长度归一化
   - 结构型（清单式并置、雅俗落差、问句不答）——高价值，但必须在正确的计量单位上判定
   - 稀有项（问句、语气词、特定词）——**绝不作为"缺失即偏离"的判据**
   - 禁忌型（这是唯一允许判"出现即偏离"的类型，例如"情绪词作谓语出现在主句"）
3. **禁止项必须与作者自身用法核对。** 任何"作者不写 X"的规则，先在作者全文里搜 X。本次"高兴"就是这么被抓出来的——**规则不能惩罚作者本人用过的东西。**
4. **哨兵回归纳入开发流程。** 判定规则集每次修改，必须跑原文句子，零假阳性才允许提交。
5. **计量单位必须显式声明。** 每条指标注明取样层级（小句／句子／段落／整篇），并且**同一指标不得跨层级比较**。
6. **短文本保护。** 样本量不足时，禁止输出分布型结论。

---

## 五、本次跑测的方法论收益

1. **"先测量、再判断"的分层架构是必要的，但还不够**——还要剥夺第 1 层的判定权。
2. **哨兵测试是有效且便宜的**：用原文自己的句子打系统，一次就抓出四个结构性假阳性。这个测试应当固化进开发流程，而不是作为一次性验证。
3. **"模仿得越努力越偏离"是一个会真实发生的失效模式**，而且方向可预测：朝通用文风收敛。这是必须在产品层面对抗的，不是靠把模型换得更强。
4. **代理漂移无法被"更准的模型"解决**，只能被**结构**约束：判定权归属、特征分级、哨兵回归、以作者自身用法校验规则。
