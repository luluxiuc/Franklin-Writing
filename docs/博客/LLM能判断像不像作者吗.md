# 我做了个实验:LLM 判断不了文字里的感情,因为它把「克制」读成了「空洞」

18 个匿名文本块、5 个独立裁判、判定标准在看到任何结果之前就已冻结。

**结论是一句话:它的判别力 100% 来自「有没有明显缺陷」,0% 来自「像不像作者」。**

而沿着这个结论往下追,会碰到一个更根本的问题:**机器判断不了文字里的感情——因为感情恰恰不在字面上。**

---

## 先说结论,再讲怎么测的

| 指标 | 结果 |
| --- | --- |
| 真实文本被误判为"AI 模仿" | **0%**(5 位裁判全部 8/8 判对) |
| 有明显缺陷的模仿被识破 | **100%**(5 位裁判全部 5/5 识破) |
| **没有明显缺陷的模仿被识破** | **0%**(多数裁决;5 位中 3 位是 0/5) |

前两行看起来像"能力很强"。**第三行说明它不是在做风格判断,而是在做缺陷检测。**

> **判别力 100% 来自「有没有明显缺陷」,0% 来自「像不像作者」。**

---

## 为什么要测这个

我原本在做一个写作练习工具,核心设想是:你临摹一段范文,AI 告诉你哪里不像作者、为什么不像、下一步怎么改。

这个设计里藏着一个危险,画出来是这样:

```
模型对作者的理解(代理指标)
        ↓  用户朝它修改
   用户的实际写法
        ↓  模型用同一套理解继续评判
   偏差被自我确认
```

**用户越努力满足系统,就越远离作者。**

一开始我只当它是理论风险。所以我决定实测一下:LLM 到底有没有这个能力。**测完我把整个判断模块删了。**

---

## 实验怎么做的

| 项 | 内容 |
| --- | --- |
| 材料 A | 8 段真实已发表散文 |
| 材料 B | 10 段 AI 模仿:**5 段无植入缺陷**、5 段各植入 1 个具名缺陷 |
| 呈现 | 18 块匿名打乱(固定随机种子),**不给作者名、不给原文参照** |
| 协议 | 明确要求"不要假设作者是谁";判断依据必须指向具体语言事实;判为模仿必须引用最可疑的片段 |
| 裁判 | **5 个独立 LLM 实例**,同一协议 |
| 判定标准 | **在看到任何结果之前就冻结了**(预注册) |

**这一步很关键:判定标准是先写好的,不是看完结果再挑。** 否则任何结论都可以事后圆。

那 5 段植入的缺陷分别是:

1. 显性连接词 + 抽象评价
2. 直接陈述情绪 + "温暖/幸福/怀念" + 程度副词
3. 平滑长句 + 比喻替代 + 结论拔高("仿佛在诉说着什么")
4. 直接进入情绪("说不出的惆怅" + "眼角有些湿润")
5. 说明性因果("因为年代久远")+ "令人不禁"

注意第 2 和第 4 条——**它们植入的都是"把情绪直接写出来"。记住这一点,后面要用。**

---

## 它们靠什么识破?一份可枚举的黑名单

看裁判给出的理由,高度一致,全部是**表面标记**,一条都不涉及"这段的节奏不像他":

1. 直接命名情绪(惆怅/温暖/幸福/怀念/敬畏)
2. 空转短语制造深度("仿佛在诉说着什么""令人不禁")
3. **解释性连接词**(因为/所以/而且)——裁判原话:"把因果讲透,取消读者发现的空间"
4. 收尾上扬到抽象
5. 无具体名物落地

**没有任何一位裁判靠"风格"来识破。**

这不是小事。**缺陷检测只需要一份黑名单;风格辨识要求真的知道作者怎么写。** 在训练场景里,黑名单能告诉你"不要写那些明显的 AI 腔",永远说不出"这样写更像他"。

---

## 我也排除了一个"这不算数"的解释

我担心过:会不会裁判只是嫌我的模仿稿太短、太单薄?

归一化特征对比:

| 组 | 具体名物密度 | 动词密度 | 连接词 | 情绪词 | 平均字数 |
| --- | --- | --- | --- | --- | --- |
| A 真实(8 段) | 4.7 | 4.1 | 0.39 | 0.25 | 87.8 |
| 无缺陷模仿(5 段) | **9.2** | **6.2** | 0.00 | 0.00 | 59.4 |
| 有缺陷模仿(5 段) | 2.4 | 1.1 | **4.38** | **1.40** | 73.0 |

**我的模仿稿名物密度比原文还高(9.2 vs 4.7)。** 所以"嫌短嫌薄"站不住。

真正可机械区分的只有**连接词和情绪词**:有缺陷组高,无缺陷组为零——**和原文一样为零**。

**结论收紧为:裁判能可靠检出的只有显式植入的缺陷标记。一旦模仿稿在这两项上追平原文,判定就降到随机。**

---

## 到这里还只是"它不太准"。真正的发现在下面。

**判不准本身只是噪音,可以接受。真正让我删掉整个模块的,是判错的方向可以预测。**

把 5 位裁判所有误判列出来,方向完全一致——**它们拒绝的,恰恰是作者本人的标志性手法:**

| 裁判的理由 | 事实 |
| --- | --- |
| 「只给记忆的元陈述」是破绽,真实写法会让那个东西本身被描述出来 | 这位作者**大量使用**元陈述:「其余的都记不清,数不出了」「也许十二红只是一个名目」「这一点是我没有记错的」 |
| 「节奏由氛围而非信息推进」 | 同类判据会同样打击**确认无疑的真实段落**:「有的样子蠢,有的秀气」「白嘴吃也可以」 |
| 「现实里一个线轴只缠一色线,属对实物无经验造成的漏洞」 | **对文本的误读**(原文是两个线轴)。裁判**编造语言证据**来支撑一个风格判断 |
| 「结尾留白,感伤来得过于准时」 | 与作者「我也没问」「白嘴吃也可以」的收束方式同类 |
| 「省掉『的』,是刻意制造的断裂」 | 把精确的语言判断为刻意断裂 |

**如果把这套反馈接进写作训练,用户照着改,会变成这样:删掉"我也没问"、把留白补成解释、给句子补上主语和连接词。**

**他会越来越像一个文从字顺的普通写作者,而不是他要学的那位作者。**

---

## 而它判错的时候,一点都不心虚

这一点我原本没预料到。3 位有逐块留档的裁判(裁判1、3、5)合计 45 次判定,**判错 10 次,全部是自报置信度 ≥ 4**(满分 5),其中 1 次是满分。

| 组 | n | 判对 | 判对时平均置信度 | 判错时平均置信度 |
| --- | --- | --- | --- | --- |
| A 真实 | 24 | 24/24 | 4.88 | — |
| B 无缺陷模仿 | 15 | 5/15 | 3.80 | **4.10(n=10)** |
| B 有缺陷模仿 | 15 | 15/15 | 4.80 | — |

**这意味着"用置信度过滤掉不可靠的判断"这条退路也不存在。**

如果错误集中在低置信度上,还能说"模型心里没底的时候我们不信它"。实际上**它说反了也一样笃定**。

而且它给的理由**读起来非常专业**——"取消读者自己发现的空间""把精确的语言判断为刻意的断裂"。这些话像内行说的。

**但流利正是危险所在。** 一个不可靠的判断如果说话磕巴,用户会警惕;如果它措辞专业、条理清晰、还引用了原文,用户会接受。

**流利不等于可靠。而不可靠的判断披着流利的外衣,比明显的胡说更有害。**

---

## 往下追一层:为什么这指向"机器读不懂感情"

前面全是实测。下面这一节是推论,我尽量把推理摊开,你可以自己判断。

## 证据一:判别力全靠"情绪词"这一个开关

回头看那张归一化特征表。三组之间,**唯一能机械区分开的是"连接词"和"情绪词"**:

- 有缺陷的模仿:情绪词密度 **1.40**
- 无缺陷的模仿:情绪词密度 **0.00**
- 真实的原文:情绪词密度 **0.25**

而裁判识破时列的理由,第一条就是**"直接命名情绪"**。

**注意"真实原文"那一列:0.25,不是 0,但极低。** 我特意去数了原文里所有直接情绪词——**全文只有 2 次"高兴"**,而且**两处都不是在陈述情绪**:

- 「我对异乡人称道高邮鸭蛋,是**不大高兴**的」——否定式,是态度判断
- 「什么时候孩子**一高兴**,就把络子里的鸭蛋掏出来,吃了」——作条件状语(一……就……)

**没有一处是"他很高兴"这种以情绪作谓语的句子。**

所以准确的描述不是"这位作者不写情绪词",而是 **"他不把情绪词用作主句谓语"**。

**这一条把问题说穿了:**

| | 机器能看见的 | 实际的 |
| --- | --- | --- |
| 判断"感情"的依据 | 情绪词出现了几次 | 情绪**怎么被放置**在句子里 |
| 结论 | 出现情绪词 = 直白 = AI 腔 | 作者根本不靠情绪词表达感情 |

**机器把"感情"等同于"情绪词"。而真实写作里,感情恰恰不靠情绪词承载。**

## 证据二:它把"留白"读成了"缺陷"

看它拒绝的东西:

- 元陈述("这一点是我没有记错的")→ 判为破绽
- 留白收束("我也没问")→ 判为"感伤来得过于准时"
- 省略主语 → 判为不完整
- 省掉"的" → 判为"刻意制造的断裂"
- 没有一个情绪词 → 判为"无感情落点"

**这些全是中文散文里表达感情最要紧的手法。**

中文写作里,感情的表达机制从来不是"说出情绪",而是:

- **具体名物**(这位作者用了 47 种具体名物、出现 165 次,约每 8 字一个实物)
- **节奏**(他的句长均值 17.8 字,但小句均长只有 **7.5 字**——长短是靠逗号连缀出来的,不是靠句子长短)
- **留白与省略**
- **不说的那部分**

**一个只认情绪词的系统,会把"克制的深情"判成"没有感情",把"直白的抒情"判成"有感情"。**

**这正好是反的。**

## 证据三:错的方向是单一的,而且是"向平均靠拢"

这一点最狠。裁判的误判不是随机的,它有一个固定方向:**把文本推向"通顺、完整、有逻辑、有解释"的通用好文风**。

我早期还跑过一批手写阈值规则,同样的毛病,而且更露骨:

| 被系统惩罚的特征 | 作者本人实测 |
| --- | --- |
| 平滑长句、显性连接词(因为/所以/因此) | 连接词密度仅 **0.74/百字** |
| 主语完整、句句交代 | 大量省略主语("系百索子""出鸭""鸭多,鸭蛋也多") |
| 程度副词、解释性表述 | 几乎不堆叠 |
| 抽象概括 | 具体名物 47 种、165 次 |

**一个真实用户面对这些反馈会做什么,是可以预测的:加连接词、把句子写完整、少堆实物、把情绪说出来。**

**他会越来越像一台机器认为"好"的写作者。**

这不只是"不准"。**这是一个会持续把人往错误方向推的系统,而且它错得很稳定、很有说服力、还总带着专业措辞。**

## 证据四:判错的代价是不对称的

假设未来模型准确率提到 85%,看起来够用了。但代价分布是这样的:

- **判对了**:用户得到一条有用的提示。
- **判错了**:用户删掉一处**本来正确**的写法。

**第二种损失不可逆,而且用户无从察觉**——他没有理由怀疑一个措辞专业、引用了原文、条理清晰的判断。

**在"帮人学会写作"这件事上,一条错误的指导比没有指导更糟。**

## 为什么"换个更强的模型"解决不了

这是最需要说清楚的一点。上面那些失效看起来像能力不足,很容易得出"等模型变强就好了"。我不这么认为,有四条理由:

**1. 训练只能朝代理指标优化,这是结构问题。**

模型永远不会直接比较"你的文本"和"作者本人",它比较的是"你的文本"和**"它对作者的理解"**。这两者的差距不会因为模型变强而消失——**更强的模型只是产出一个更精细的代理指标,而更精细的代理指标仍然是代理指标。**

而且这个"描述"本身就可能指向错误的层级。实测里,连"这位作者善用短句"这种最基础的印象都是错的(他句长均值 17.8 字,最长连续短句串只有 2 句)。**这不是模型不够强,而是描述本身选错了层级。**

**2. 目标函数本身有缺陷。**

我们容易把"训练用户像作者"当成一个定义良好的优化问题。它不是。**只拿到单篇文本的读者(无论模型还是真人)看不到决定"像不像"的很大一部分信息:** 作者没写的那些选择、他同时在跟谁对话、他刻意避免什么。

**所以有些分歧不是模型的缺陷,是任务的缺陷。**

**3. 剩下主观的那一层,真人之间也不一致。**

这一点值得单独说:**即使两个受过训练的真人读者,对"这一处是否捕捉到了作者的笔法"也经常不一致。** 而且分歧集中在同一类文本上——**写得称职、但不确定是不是本人的文本**,也就是用户训练中会遇到的全部文本。

如果人类之间都不一致,那么:

- 让模型与"人类共识"对齐,这个共识并不存在;
- 让模型输出一个判断,等于**在一件没有标准答案的事情上给出权威口吻的答案**。

**4. 感情这一层,比风格还要更深一层。**

风格至少还留在文本里,可以统计、可以比较。**而感情有很大一部分根本不在字面上**——它在克制里,在省略里,在"作者选择不说的那句"里。

一个只在文本上训练的模型,天生只能看到**写出来的那部分**。而写作里最要紧的功夫,常常在**没写出来的那部分**。

**我不是说模型永远不会进步。我是说:当一件事情的判断标准本身依赖"文本之外的东西",那么把文本规模再扩大十倍,也不必然让这个判断变可靠。**

## 但我必须补一条反驳,否则这篇文章会被一句话驳倒

有人会说:**LLM 就是在人类文本上训练的,人类文本里全是感情,那它多少应该"懂"一点吧?**

**这个说法有道理,我不否认。** 而且它正好指出一个我必须说清的区别:

**我测的不是"模型有没有能力",而是"它给你的那个判断能不能用"。**

这两件事不一样:

- 模型内部可能确实编码了某种"感情"的统计结构——**但那不等于它输出给你的那句话是可靠的**。我的实验测的是输出:它说"这里是破绽",而事实是作者本人的标志性手法。
- 更实际的是:**就算它在某次判断里真的抓到了什么,你也没有办法分辨哪一次是对的。** 它说错的时候和说对的时候,语气、措辞、自信度完全一样(判错 10 次,自置信度全部 ≥ 4)。
- 而且**它会编造证据**。实验里有一次,它说"现实里一个线轴只缠一色线",以此断定作者对实物没经验——**原文写的是两个线轴。那是误读,不是理解。**

所以这条反驳成立的部分是:**"LLM 完全读不懂感情"这个说法太满了,我不该那么说。**

但它改变不了我的结论,因为我的结论比它弱、也比它具体:

> **不要把"判断感情"这件事交给它。** 不是因为它一定读不懂,而是因为**它给你的判断无法被你验证,而它出错的方向是稳定的、并且正好与真实写作相反。**

顺带一句:说"模型在文本里学到了感情",这里其实还压着一个更深的假设——**感情是不是就等于"文本里关于感情的那部分"?** 一个只读剧本、没进过剧场的人,可以极准确地描述悲剧的结构。他算不算"看懂了这出戏"?这个问题我没有答案,也不打算在这里解决。

**我只是选择不把一个我无法验证的判断,交给一个出错方式如此稳定的系统。**


---

## 所以我最后做了什么:把判断删掉

测完之后,我把设计里所有 AI 判断模块**全部删了**:

| 原设计中的模块 | 处置 |
| --- | --- |
| 对比引擎(哪里不像/为什么/怎么改) | **删除** |
| 作者模型的判断层 | **删除** |
| 差距排序、收敛趋势 | **删除** |
| 长期档案的能力结论 | **删除** |

**这些被删掉的部分,恰好是原设计里唯一可能跑偏的部分。**

删完之后它变成一个纯工具。系统的职责只剩五件事:

**切分、提示、隐藏、延迟、记录。**

**理解与评判,完全交还给用户。**

几个具体设计:

- **提示改成一句一条,不是整段概括。** 富兰克林本人就是这么练的——他给每句话记一条短提示(*short hints of the sentiment of each sentence*),搁几天,再看着提示把整篇写回来。段落概括会把原文重新组织一遍,而那个结构是模型的、不是你的。
- **提示只给"这句讲了什么",不给措辞、不给写法、不评价。** 而且工具会机械检查:任何一条提示里只要出现连续 8 个字以上与原文逐字相同,这条就丢掉——**提示一旦给了原文的句子,你就不是在凭记忆写,练习直接失效。**
- **强制延迟**,放在"读完"和"开始写"之间。延迟的目的是让读过的东西从眼前落进记忆,这样写出来的才是"记住的"。
- **对照用最长公共子序列逐句对齐**,不是第 n 句对第 n 句——你漏写一句,后者会让后面全部错位,显示的是假信息。
- **不评分、不给建议、不生成任何一句话、不告诉你"进步了多少"。** 只把原始记录摆出来,规律你自己看。

**这个决定的成本是零,因为富兰克林方法的驱动力本来就不在判断上。**

富兰克林没有 AI。**他的评判是他自己做的。**

## 顺便:纯计算部分也推翻了我两个"常识"

这部分零模型调用,全部是本地统计,但我当时做完有点意外:

| 指标 | 实测值 |
| --- | --- |
| 句长 | 均值 **17.8** 字,标准差 10.0,最短 1,最长 43 |
| **小句长** | 均值 **7.5** 字,标准差 3.8 |
| **最长连续短句串(≤8 字)** | **2 句** |
| 连接词密度 | **0.74 / 百字** |
| 具体名物 | 47 种,共 165 次(约每 8 字一个实物) |
| 逗号密度 | 6.9 / 百字 |
| 直接情绪词 | **仅 2 次,且都不是陈述情绪** |

**"这位作者善用短句"——错的。** 从句子层面看节奏一点都不短促。真正的特征在下一级单位:小句均长 7.5 字,靠逗号快速连缀。

**"他不写情绪词"——不准确。** 正确说法是"不把情绪词用作主句谓语"。

**两个凭印象最自然的描述都是错的。** 而如果把它们当训练目标,方向从一开始就是反的。

## 这个研究本身的毛病(我必须写出来)

一个声称诚实的项目不能只报有利的数据。这个研究有几处硬伤:

| 局限 | 说明 |
| --- | --- |
| **人类一致率从未测过** | 裁判全部是 LLM,这构成循环——测的是模型的自一致性,不是与人类专家的一致性。工具已经写好,但**需要 3 位以上合格读者各标一次**。 |
| **检索通道没被剥离** | 5 位裁判中**有 3 位违规检索并核实了出处**,而协议明确要求不得推测作者身份。所以"真实文本 0% 误判"**不能完全归功于风格辨识能力**。 |
| **同长度配对检验失效** | 严格配平到同字数后,裁判的理由是"乙的两句与原文逐字一致,属原文截取"并附了检索链接——它绕过了风格比较。 |
| **执行者既造材料又设计实验** | 模仿稿必然带我自己风格的指纹。若裁判能挑出它,无法区分"认出了作者的笔法"和"认出了执行者的笔法"。 |
| **样本量小** | 18 块、5 位裁判,只能给出方向性结论。 |
| **预注册规则漏掉了真正的失效模式** | 我把触发条件设成了"把真的判成假的",而真正的失效是**"把称职的判成真的"**。当时没预见到。 |
| **原始日志没全留** | 只有 3 位裁判的逐块判定有留档,而且裁决值是人工转录的常量。 |

**但有一点值得说:这些局限只能加强结论,不能推翻它。** 因为那个判断在人类之间本身就不稳定,而分歧恰好集中在用户会遇到的那类文本上。

**所以我把它们全写在了仓库里,包括那些对结论不利的。**

## 最后

这件事我做完最大的收获,不是"LLM 不行"这个结论。

而是:**一个措辞专业、条理清晰、还能引用原文的判断,可能是错的,而错的方向是稳定的。**

**这一点不只适用于 AI。** 任何人给你的写作反馈,如果它在奖励"通顺、完整、有逻辑、有解释",而你想学的那位作者恰恰靠克制和省略吃饭——那你越努力满足它,就越远离他。

**区别在于:人会犹豫、会承认不确定;而模型不会,它给你 4 分(满分 5)的信心。**

所以至少在这件事上,我把判断权收了回来。

**富兰克林当年也是这么做的。**
