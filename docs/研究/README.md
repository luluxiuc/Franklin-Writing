# 研究：LLM 能不能判断「像不像作者」

这个目录放的是本项目的**决策依据**,不是宣传材料。

本工具之所以**不评分、不评价、不说"像不像作者"**,不是因为做不到,而是因为**我们把它测了一遍,然后主动删掉了这个功能**。这里是从实验设计到原始数字的全部材料,包括对我们自己不利的部分。

> **English:** [docs/research/](../research/) — the same reports in English.

---

## 结论(一句话)

> **判别力 100% 来自「有没有明显缺陷」,0% 来自「像不像作者」。**

5 位独立 LLM 裁判 / 18 个匿名文本块 / 预注册判定标准:

| 指标 | 结果 |
| --- | --- |
| 真实文本被误判为模仿 | **0%** |
| 植入明显缺陷的模仿被识破 | **100%** |
| **无缺陷的模仿被识破** | **0%** |

而且**误判方向是系统性的**:裁判拒绝的恰恰是作者本人的标志性手法。接入训练反馈的话,用户会越来越像一个"文从字顺的普通写作者",远离他要学的那位作者。

## 我们自己研究里的问题

**一个声称诚实的项目不能只报有利的数据。** 以下是这项研究本身的缺陷,全部记录在案:

| 局限 | 说明 | 状态 |
| --- | --- | --- |
| **人类一致率从未测过** | 裁判全部是 LLM,构成循环——测的是自一致性,不是与人类专家的一致性。工具已备好(`_capability/human_kit.py`),**需要 3 位以上合格读者各标一次**。 | 待做 |
| **检索通道没被剥离** | 5 位裁判中有 3 位违规检索并核实了出处,而协议明确要求不得推测作者身份。**所以「真实文本 0% 误判」不能完全归功于风格辨识能力。** | 待做 |
| **补充的同长度配对检验失效** | 严格配平到同字数后,裁判的理由是"逐字一致,属原文截取"并附了检索链接——它绕过了风格比较。 | 已记录 |
| **实验二已设计未执行** | 单句判别才是能把"风格判断"与"篇幅判断"彻底分离的设计。 | 待做 |
| **执行者既造材料又设计实验** | 模仿稿必然带执行者自己的风格指纹,无法区分"认出了作者的笔法"与"认出了执行者的笔法"。 | 结构性限制 |
| **样本量小** | 18 块、5 位裁判,只能给出方向性结论。 | 已记录 |
| **预注册规则漏掉了真正的失效模式** | 触发条件设成了"把真的判成假的",而真正的失效是"把称职的判成真的"。修正判定的推理过程一并写明,以免变成事后挑选标准。 | 已记录 |

**但这些局限只能加强结论,不能推翻它**:该判断在人类之间本身就不稳定,而分歧恰好集中在用户会遇到的那类文本上。
