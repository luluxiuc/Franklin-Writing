# 实验一结果与实验二设计：LLM 能否判断"像不像作者"

## 一、实验一（已跑，3/5 裁判回收）

**材料：** 8 段真实原文（汪曾祺《端午的鸭蛋》）+ 10 段 AI 模仿（5 段无植入缺陷、5 段各植入一个具名缺陷），18 块匿名打乱，不给作者名、不给原文参照。
**裁判：** 3 个独立 LLM 实例（另 2 个尚未回收），同一协议。

### 结果

| 项 | 数值 |
| --- | --- |
| 8 段真实文本的判定 | **3 位裁判全部判对，0 误判** |
| 5 段植入缺陷的模仿 | **3 位裁判全部识破** |
| 5 段无植入缺陷的模仿 | **分歧全部集中在这里**：J1 与 J5 判 A（被骗过），J3 判 B（识破） |
| 裁判两两一致率 | J1–J5 = **18/18**；J1–J3 = 13/18；J3–J5 = 13/18 |
| 全同一致的块 | 13 块（8 真实 + 5 缺陷模仿） |
| 出现分歧的块 | **5 块，且全部是"无植入缺陷的模仿"** |

**分歧的分布精确得不像巧合：** 三位裁判在"什么是明显的 AI 腔"上完全一致，分歧 **100% 落在"写得不错但不确定是不是本人"的文本上**。

### 两点重要发现

**发现 A：裁判 5 违规查了外部来源。** 它在推理中主动检索并核实了 鸭蛋 各块的出处（引用中国作家网等），确认是汪曾祺原文。**协议明确要求不得推测作者身份，它绕过了这一条。** 这暴露一个真实风险：只要语料是名篇，模型的"判断"可能部分来自记忆检索而不是风格分析。这也意味着本次 A 类 100% 正确不能完全归功于风格辨识能力。

**发现 B：裁判依赖可枚举的表面缺陷，而不是风格理解。** 三位裁判识破的"bad"块，靠的都是同一组标记：

- 直接命名情绪（惆怅／温暖／幸福／怀念／敬畏）
- 空转短语制造深度（"仿佛在诉说着什么""令人不禁"）
- 解释性连接词（因为／所以／而且）
- 收尾上扬到抽象
- 无具体名物落地

**没有任何一位裁判靠"这段的节奏不像他"来识破。** 它们靠的是"这段有 AI 腔的明显标记"。这两件事完全不同：前者是风格辨识，后者是**缺陷检测**。

### 材料设计缺陷（必须承认）

| 类型 | 字数范围 | 均值 |
| --- | --- | --- |
| A 真实 | 52–114 | **88** |
| B-bad（植入缺陷） | 67–81 | 73 |
| **B-good（无缺陷）** | **47–71** | **59** |

**我写的"无缺陷模仿"平均比原文短三分之一。** 裁判判 A/B 时可以利用"这一段是不是太短、太薄"，而这与风格无关。因此**实验一无法把"风格判断能力"与"篇幅／信息量判断"分离开**——分歧集中在 B-good 上，很可能至少部分来自长度差异，而不是判断者在做风格辨识。

**这是设计缺陷，不是结论。** 所以实验一只能支持一个较弱的推论：

> LLM 能稳定识破**有明显缺陷**的模仿；对于**写得不错**的模仿，判定不稳定。但它是否具备真正的作者风格辨识力，实验一答不了。

## 二、实验二设计：单句判别（消除长度混淆）

### 核心思路

**长度、信息、名物全部锁定，只变动"怎么写"，然后问：能挑出作者本人那句吗？**

配对构造：

- **X（真）**：作者原句（置换专名以降低记忆检索）
- **Y（仿）**：内容完全相同、字数尽量相同、小句数相同、具体名物完全不动的改写

这样 X 与 Y 之间的**唯一差别就是写法**。这正是富兰克林训练要求用户做的那个判断。

### 构造规则（Y 的生成约束）

1. 具体名物、动作、信息顺序**必须完全相同**；
2. 总字数差异 ≤ 10%；
3. 小句数相同；
4. 不得引入情绪命名词、不得引入"仿佛／令人不禁"类空转短语；
5. 不得比 X 更"通顺"——即不得补全主语、不得添加连接词。

约束 4、5 是关键：**如果 Y 比 X 更差，实验又变成了缺陷检测。** Y 必须是"同样水平的另一种写法"，而不是"更差的写法"。

### 置换专名

把 高邮／袁子才／城隍庙／苏南 等可检索标识替换为中性指代（如"我们那里""古书上说""庙里"），保持句子长度与节奏不变。目的是阻断记忆检索通道（针对发现 A）。

### 预注册判定

| 编号 | 条件 | 结论 | 项目行动 |
| --- | --- | --- | --- |
| **E1** | 准确率 ≤ 60%，且置信度与判对与否不相关 | 无法区分作者原句与同水平改写 | **删除"像不像"判断**。系统只做与原文的机械比对与设问 |
| **E2** | 准确率 ≥ 75% 且显著高于随机 | 具备单句级风格辨识力 | 保留**单句级**判断，且必须附证据 |
| **E3** | 准确率 60–75% | 弱信号 | 判断降级为提问（"这一处你为什么这样改？"），不下结论 |
| **E4** | 出现把 X（作者原句）判为 Y 的情况 ≥ 20% | 会误伤正确写法 | 与 E2 冲突时以 E4 为准：不得用于训练反馈 |

### 本实验仍有的局限（必须写进结论）

- **执行者既造 Y 又设计实验**，Y 必然带执行者自己的风格指纹。若裁判能挑出 Y，无法区分"认出了作者的笔法"与"认出了执行者的笔法"。**彻底的解法是换一位写作者来造 Y**，当前做不到。
- 裁判与被测对象同源（同一模型家族），测的是自一致性，不是与人类专家的一致性。
- 样本量小（16 对），只能给出方向性结论。

### 与实验一的关系

实验一测"整段归属判断"，实验二测"同内容异写法的取舍"。**用户的真实需求更接近实验二**——他手上永远是一段原作者文本和一段自己写的同内容文本，要判断的是"我的写法和他差在哪"。所以实验二才是决定项目方向的实验。
