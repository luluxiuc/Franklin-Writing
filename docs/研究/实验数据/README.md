# 实验数据与脚本

这里放实验一的**原始判定、材料参数和全部分析脚本**。研究报告中每一个数字都应该能在这些文件里找到出处。

---

## 里面有什么

| 文件 | 是什么 |
| --- | --- |
| `PREREGISTRATION.json` | **预注册的判定规则。** 在看到任何裁判结果之前冻结。D1–D5 五条规则、必须同时报告的负面结果、以及本测试**不能**证明的事。 |
| `key.json` | 材料答案:18 块的打乱顺序(`order`)、哪 8 块是真实的(`A_ids`)、10 段模仿各自的植入缺陷说明(`B[*].quality` / `.note`)。 |
| `judge1.json` `judge3.json` `judge5.json` | 3 位裁判**逐块留存**的判定:裁决、自报置信度。 |
| `build_material.py` | 材料构造脚本:匿名化、固定种子打乱,含全部参数。 |
| `score.py` `final_stats.py` `analyze_disagreement.py` | 打分与统计。 |
| `confidence_stats.py` | 裁判自报置信度与判对与否的关系。 |
| `verify_aggregates.py` | 用 5 位裁判的裁决重算交叉表,核对报告里的汇总数字。 |
| `verify_report.py` | 核对报告正文引用的数字与数据文件是否一致。 |
| `fingerprint_compare.py` | 归一化特征对比(纯计算,用来排除"裁判只是嫌稿子短"这个替代解释)。 |
| `analyze_fingerprint.py` | 统计指纹计算(纯计算,零模型调用)。 |
| `human_kit.py` | 真人标注工具:**生成不含答案的标注材料**、收集标注、算人类两两一致率并与 LLM 裁判对照。实验一缺的那一环就靠它。 |
| `store_judges.py` | 把已回收的裁判判定写入 `judgeN.json`。**注意:裁决值在这个脚本里是人工转录的常量**,原始采集通道未留档。 |

## 复算

```bash
cd docs/研究/实验数据

python analyze_fingerprint.py     # 统计指纹(纯计算,不要 Key)
python fingerprint_compare.py     # 归一化特征对比(纯计算)
python verify_aggregates.py       # 5 位裁判交叉表 vs 报告
python confidence_stats.py        # 置信度 vs 判对与否
```

## 三件必须说清楚的事

### 一、仓库**不包含**语料文本

实验材料是 **8 段真实已发表作品 + 10 段模仿稿**,合起来 18 块完整文本。这些文本**不在仓库里**:

- 那 8 段是受版权保护的已发表作品,**不能随仓库分发**;
- 模仿稿全部是照着那 8 段写的,**脱离了原文也就没有意义**。

所以 `blocked.json`(18 块全文)与由它生成的 `人工标注材料.md` **已被排除**。你需要自己从公开来源取得语料,然后:

```bash
python build_material.py       # 按 PREREGISTRATION 的参数重建匿名块
```

打乱用的**固定种子**记录在 `build_material.py` 里,所以重建出来的块序与当年的实验一致。

### 二、只有 3 位裁判的逐块判定有留档

实验一共跑了 **5 位**裁判。逐块文件只留存了 3 位(`judge1` / `judge3` / `judge5`)。**裁判 2、4 的裁决只存在于研究报告的表格里**,原始采集记录未留存。

- `verify_aggregates.py` 里同时放了这 5 位的裁决,跑一遍会得到报告中的交叉表(裁判2 = 16/18,good 识破 3/5;裁判4 = 13/18,good 识破 0/5);
- 但**置信度只有 3 位有**,关于置信度的统计只覆盖这 3 位;
- 这是记录方式的缺陷,写在这里而不是藏起来。

### 三、裁决值是人工转录的

`store_judges.py` 里的裁决是**人工转录的常量**,不是从采集日志自动读出来的。这意味着:

- 转录错误的风险是真实存在的。**我们做了什么来兜底:** `verify_aggregates.py` 用报告表格里的 5 位裁决重算了一遍交叉表,与报告完全一致;`verify_report.py` 另外核对正文引用的数字。
- 但这只证明**转录与报告自洽**,不能证明**转录与当时模型的原始输出一致**——因为原始输出没有留档。
- 想彻底解决,只能重跑一遍并保留原始日志。**这正是 [`ROADMAP.md`](../../../ROADMAP.md) 上的一项。**

## 关于置信度的发现

用 `confidence_stats.py` 可以复算:

| 组 | n | 判对 | 判对时平均置信度 | 判错时平均置信度 |
| --- | --- | --- | --- | --- |
| A 真实 | 24 | 24/24 | 4.88 | — |
| B 无缺陷模仿 | 15 | 5/15 | 3.80 | **4.10(n=10)** |
| B 有缺陷模仿 | 15 | 15/15 | 4.80 | — |

**10 次判错,全部是自报置信度 ≥ 4,其中 1 次是满分 5。**

这条数据的意义:**判错不是犹豫出来的。** 如果错误集中在低置信度上,那还能说"模型心里没底,我们可以用置信度过滤掉"。实际上它说反了也一样笃定——这与"判错方向是系统性的"合起来,正好解释了为什么这类判断一旦接进训练反馈就特别有害:用户看不到任何可疑的信号。

**但这条数据不能过度解读:** 置信度是**模型自报的**,未经独立校准。它足以说明"这些不是低置信度的取舍",**不能**当作模型具有良好校准的证据。
