## 那些被删掉的设计,为什么还留在仓库里

`核心方法-v0.3.md` 和跑测报告描述的是**一个没有做出来的产品**,包含对比引擎、作者模型判断层、差距排序、收敛趋势。

留着它们有两个理由:

1. **它们是删除的依据。** 没有跑测报告里那四个假阳性,"不做判断"就只是一句立场;有了它,才是一个有证据的决定。
2. **它们记录了失败的路。** 如果将来有人想重新引入 AI 判断(这种情况一定会发生),先读完这两份,能省掉重复踩一遍的时间。

**但请注意:它们描述的设计已经不是这个项目要做的产品。** 不要照着它们实现。
