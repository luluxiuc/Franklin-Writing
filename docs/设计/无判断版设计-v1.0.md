# 富兰克林写作工具（无判断版）：设计 v1.0 草案

> 触发条件：若 LLM 风格判断能力测试的结论是 D1／D2／D5（判断不可靠），本项目即转为本设计。
> 本设计与 v0.3 的关系：保留 v0.3 的**全部训练结构**，删除**全部 AI 判断**。

---

## 1. 一句话定位

**把富兰克林写作法做成一个顺手、可坚持的流程工具。系统负责切分、提示、隐藏、记录；理解与评判完全由用户自己完成。**

不是"AI 帮你写作"，也不是"AI 评价你的写作"，而是：

> **AI 帮你把该做的动作按正确顺序摆好，剩下的你来做。**

## 2. 被删掉的东西

| v0.3 中的模块 | 处置 | 理由 |
| --- | --- | --- |
| 对比引擎（哪里不像／为什么／怎么改） | **删除** | 判断不可靠；且用户自己看原文即知 |
| 作者模型第 2 层（LLM 判定项） | **删除** | 同上 |
| 作者模型第 4 层（与同类的差异） | **删除** | 依赖判断 |
| 风格迁移的"作者区间命中率" | **删除** | 依赖判断 |
| 专注项、差距排序、收敛趋势 | **删除** | 全部依赖判断 |
| 长期档案的能力结论 | **删除** | 同上 |

**关键认识：这些被删掉的东西，全部是 v0.3 里唯一可能跑偏的部分。** 删掉它们，代理漂移风险归零，不再需要哨兵回归、校准集、盲测——因为系统不再做任何关于"像不像"的断言。

## 3. 留下的东西（这是产品的全部）

### 3.1 切分（程序 + 用户确认）

- 按认知负荷把文章切成训练单元（默认按长度与结构复杂度切，允许一键重切）。
- **不做表达动作命名**（那是一种解读）。只报告规模：多少字、几句、几个小句。
- 切分结果保存，重切历史保存。

### 3.2 重构提示（唯一涉及生成的模块，且受限极严）

- 提示**只描述内容骨架**，不描述修辞、不描述写法、不描述效果。
- 格式：由程序从原文**机械抽取**——出现的具体名物、动作、顺序。
  - 例：`丝线／手腕／香角子／帐钩／五毒／门槛／符／城隍庙`
- **把"提示"做成关键词清单，而不是句子描述。** 这样它无法携带任何解读，也几乎不泄露措辞。
- 用户可以关掉提示。历史记录里标注"本轮使用了提示"，供自己参考。

### 3.3 强制重构（编辑器即训练场）

- 禁止粘贴；无实时纠错；无拼写红线；无任何建议。
- 提交后，本单元内不再提供二次查看原文的入口（原文在对照阶段自然出现）。
- 提供"我记不起来了"按钮：如实收下不完整的稿子，不给提示、不给梯子。
- **延迟机制：** 提交后强制等待（默认 10 分钟，可配），期间不能查看原文。这是富兰克林方法的核心动作，值得做成不可跳过的约束。

### 3.4 并置对照（产品的真正主体）

去掉 AI 判断之后，这个界面从辅助功能变成核心功能。要求：

- **原文与用户稿逐句对齐并排**，同屏、同字号、同排版。
- 用户稿中**未命中的原文具体名物自动标记**（机械比对，非判断）。
- 差异由用户自己看、自己说。
- **提供"我的观察"输入框**：用户写下自己看到的差异。这是唯一被保存的"评判"，而且它是用户自己的。
- 可选：把"我的观察"与上一轮的对照，看自己的注意力变化。

### 3.5 记忆覆盖率 M（机械计算，唯一保留的量化指标）

- 计算原文中的具体名物、专名、关键动词在用户稿中的**命中率**。
- 这是**纯字符串/词表比对**，不是判断，因此可复现、不会跑偏。
- **报告方式严格限定为事实：** "原文出现 12 个具体名物，你的稿子里出现 5 个"，并列出缺的是哪 7 个。
- **禁止**换算成分数，**禁止**说"你记住了多少"，**禁止**给"保真度"这类命名。只列清单。

### 3.6 历史与档案（只记事实，不下结论）

- 每轮记录：单元、时间、是否用提示、M 的命中清单、"我的观察"原文、用时。
- 档案**不做归纳**。系统不告诉你"你习惯性遗忘环境描写"——那也是一种判断。
- 取而代之：**把可能显示模式的原始数据摆出来**，让用户自己看。
  - 例：列出最近 10 次训练各自缺失的名物清单。用户自己会不会看出"我总是丢掉环境类名物"，由他自己判断。

## 4. 一个仍然存在的风险，以及处置

**风险：** 用户可能自己也不做比较，草草提交、直接进入下一单元——工具没有判断力，也就没有"被抓住"的压力。

**处置：** 不做强制评分，但做**流程约束**：
- 提交后必须进入并置对照界面，且**必须写上至少一条"我的观察"**才能结束该单元（可写"我看不出差别"，但必须显式写出）。
- 记分不是记好坏，而是**记录是否完成了动作**：本轮是否脱离原文、是否等待、是否完成对照、是否写下观察。这是**流程完成度**，不是写作水平。

## 5. 与 v0.3 相比的取舍（明说）

| | v0.3（有判断） | 本设计（无判断） |
| --- | --- | --- |
| 学得到的东西 | 可能更多（有指路） | 依赖用户自己的观察力 |
| 跑偏风险 | 高且已实测 | **零** |
| 成本 | 每轮多次模型调用 | 近乎零（提示为机械抽取） |
| 隐私 | 需联网 | 可以完全离线 |
| 开源价值 | 需要校准集与哨兵维护 | 轻、易复现、易被别人验证 |
| 诚实性 | 系统必须不断证明自己没跑偏 | 系统从不声称自己在评判 |

**核心判断：** 富兰克林方法的驱动力是"主动重构 + 延迟 + 自我对照"，不是"被告知差距"。研究报告自己引用的研究也指出，反馈的数量并不保证效果，**学习者的实际参与才是关键**。删掉判断，等于把全部学习压力放回它原本该在的地方——用户自己身上。

## 6. 本设计仍可被检验的东西

删掉判断不等于无法验证。仍然可以测：

1. **流程是否被坚持**：完成率、平均轮次、放弃点在哪里。
2. **自我观察是否变化**：用户写的"我的观察"在 10 轮前后，是否从"词不一样"变成"结构不一样"。
3. **迁移写作是否变化**：用未参与训练的新文本，比较第 1 次与第 10 次。**由用户自己判断**两者差别，系统只负责把两份稿子并排摆出来。

这三项都不需要系统做任何风格判断，也就都不会把用户带偏。
